# Product and engineering notes

Sovi is an Austria-first organizational companion. People can join at any life stage; the supplied 1993–2026 example forms a fictional 33-year-old male’s path. All years remain visible in one continuous scroll. The first implemented journey is organizing next steps after a synthetic hospital discharge.

The path is the normal interface, with one companion and no tabs or dashboard. Tasks work directly through previews; conversation offers proposals and never authorizes itself. Medication is a bounded synthetic extension, not clinical advice.

Read `../README.md`, `../DEMO.md`, `../AI_INTEGRATION.md`, and `VALIDATION.md` for the current implementation, walkthrough, service contracts and native verification status. Real health data, caregiver authority, privacy/legal intended purpose and general extraction remain separate future product decisions.
